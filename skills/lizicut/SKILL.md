# Lizicut · 让画面承担解释工作

把用户的表达意图转成可观看、可理解、可继续编辑的视频。默认由智能体通过当前可用的 Premiere MCP 操作 PR，以实际序列和 `.prproj` 为主工程，最终从 PR 导出。沿用已有内容、素材和品牌，默认采用克制的财经解释风格；用户指定的题材、风格和其他执行端优先。单纯转码、下载或裁切不需要整套流程。

## 接续本次任务

从对话和实际文件恢复准确文稿、可改写范围、受众、已有录音/字幕/视频、规格和交付终点：方案、资产、预览或成片。已有结果从缺口继续，不重新采访或重做所有阶段。未指定比例时可从 16:9 开始；这只是默认值。

缺失信息只有在改变表达、正确性或真实外部动作时才询问。缺音频可先做语义草案和估算时长；不得把估算冒充强制对齐。图文配乐或明确静音的视频可按阅读与节拍设计固定时长，不必强加 TTS；不能拿这条路径替代用户要求的有声解说。

## 主流程与确认

按已有进度接续，不为走流程重做已完成阶段。文稿和录音是两个不同的确认对象：从对话沿用对准确版本的明确确认，不因换会话重复询问；用户明确委托智能体定稿或选录音时，在该授权内完成并说明依据。尚无确认或相应委托时，先给出可审阅的具体版本，等待该节点确认；可并行准备不依赖它的工作。不能把完成整片的要求、测试夹具锁定或沉默记为用户确认。

| 阶段 | 执行与进入下一阶段的依据 |
|---|---|
| 文稿确认 | 核对原意、事实口径、数字、可改范围与解释结构，给出准确稿件/版本及待核实项。改变结论或事实的修改重新确认受影响部分。 |
| 录音确认 | 指定实际主音视频、版本、时长、轨道、转录与同步关系；核对缺句、错词、数字及声音质量，给出补录或择优建议。确认的是原始录音基础，粗剪后仍要复核切口。 |
| PR 口播粗剪 | 按现有粗剪规则择优与删减，在独立工程或序列副本实施真实源区间；默认相邻 V1/A1 0 帧间隙，按硬门槛审计 5–8 帧例外、超过 8 帧失败、片段内部静音/黑帧候选和目标序列一致性。 |
| 素材搜集与生成 | 按粗剪后的解释单元复用、检索或生成，核验并落盘，记录来源和用途；导入 PR 后核对实际项目项。 |
| 设计视觉与动效思路 | 确定画面载体、信息关系、背景/元素/模板、阅读次序、声音落点及动作目的；先定可读画面，再决定哪些元素需要运动。 |
| 可选 PS / Illustrator / AE 协作 | PS/AI 定版并保留可编辑源；复杂动效按需在 AE 制作。检查渲染与交接素材后导入 PR，不把跨软件计划当作已完成制作。 |
| PR 编排与动效 | 实际上轨、安排独立图层，用已发现的效果、关键帧或真实 MOGRT 实施动作，回读并检查画面。 |
| 对齐与精修 | 在粗剪后的序列时钟下对齐人声、字幕、资料原声、图形与音乐；逐个核查新接缝、字幕源映射、字幕可见性及关键落点，修正后再锁定输出版本。 |
| PR 输出与审片 | 保存工程，检查缺失媒体与导出规格，使用真实编码预设输出；核查实际视频，交付 `.prproj`、关联素材、字幕和视频。 |

开始 PR 操作前读 [Premiere 执行](references/premiere.md)。需要跨软件设计时再读 [Adobe 可选协作](references/adobe-collaboration.md)。用户只要方案或粗剪时停在该交付终点；确认后连续完成其余已授权阶段，不逐刀、逐素材或逐关键帧重复请求批准。

## 剪辑判断

1. **先抓解释任务。** 通读整篇，明确问题、论点、证据和收束。按观众要看懂的关系组织解释单元；标点辅助字幕定位，不自动决定换镜。
2. **决定画面如何工作。** 区分载体（主播、实拍/资料画面、设计画面）、信息关系（比较、变化、流程、空间等）与证据来源。分别选择背景、前景元素和信息模板，按解释需要组合；不是每镜都集齐三层。主播与实拍都可以叠加结构化信息。一个单元先有一个主解释任务，再加入必要辅助表达。
3. **锁定时间依据并处理口播。** 有录音时以实际声音为主时钟。先区分转写错误、真实重录、语义重复与自我纠正，再决定删减；重录择优不默认留最后一遍。保留有效换气、句头句尾、限定和转折；按真实切口处理呼吸与跳切。粗剪后同步更新音视频、字幕和源时间映射，置信度不足的候选先保留。
4. **取得所需素材。** 先用现有且合适的素材，按镜头/图层的具体用途检索。打开原页与实际内容，先核对身份、证据和使用条件，再比较解释效率、构图与可用时长。搜索词和生成提示词分别写；生成图像承担示意、氛围或隐喻，不能代替事实证据。选定后下载/采集到本地，保留出处、选择理由、授权状态与镜头绑定；链接或候选预览不算完成。
5. **组织阅读与连续性。** 模板文字提炼关键词和关系，字幕保留准确口播。相邻语句仍解释同一关系时沿用板面、物件或坐标并推进状态。需要新对象、新证据或新阅读任务时再换板。
6. **让动作与声音服务理解。** 先把图层挂到真实语句/关键词上，再安排入场、可读保持和交接；只有句级时间时保守呈现完整关系，不捏造词级落点。默认前快后稳，硬切与有目的的推拉为主；BGM 按段落发展，旁白和原声都应听清，音效只强调有意义的事件。
7. **交付到实际终点。** 需要成片时继续合成、导出和回看。发现内容、时序或阅读问题，回到拥有问题的源层修复，并更新受影响产物。

具体选择读 [剪辑判断与画面选择](references/editorial-rules.md)；处理录音、粗剪和字幕读 [音画时间](references/timing-and-roughcut.md)。不要为执行分类额外调用旧站模型，当前智能体可直接根据这些规则判断。

## 按需使用资料

- 新建财经/商业解释视频，或需要统一整片气质：读 [财经解释风格](references/finance-profile.md)。其他题材沿用用户风格，不强行套财经外观。
- 素材、证据板、背景、版式、动效、配乐或音效需要制作：读 [视觉与声音](references/visual-and-sound.md)。
- 需要实际检索、挑选、下载或导入素材：读 [素材搜索与落盘](references/material-search.md)，沿用已有工具；无素材管理后端时可用 materials 助手。
- 要在 PR 实际剪辑、做动效、对齐和输出：读 [Premiere 执行](references/premiere.md)，发现当前 MCP 的真实能力，不固定依赖某个服务器名称。
- 要操作 PS / Illustrator 定版，或在 AE 制作复杂动效：读 [Adobe 可选协作](references/adobe-collaboration.md)。这些是可选分支，不是普通剪辑的前置依赖。
- 需要本地素材整理、字幕重映射、媒体检查，或用户选择 FFmpeg 合成：读 [辅助工具与 FFmpeg 时间线](references/execution.md)。不要求 PR 任务另建一套本包合成时间线。
- 需要理解来源或调整默认规则：读 [提取来源与取舍](references/source-notes.md)。历史材料中的“必须”是当时项目约束，只有本次仍适用的部分才沿用。

## 本地工具

下列路径相对于本 Skill，用于辅助处理或用户选择的 FFmpeg 路径。PR 是默认执行端；不能因桥接失败自动改交压平视频。Python、FFmpeg/ffprobe、转录、素材生成与 Adobe 软件按实际需要发现，缺少时说明具体缺口，不自动安装或引入新服务。

```text
python scripts/lizicut.py doctor
python scripts/lizicut.py roughcut roughcut-plan.json --output-dir output/roughcut --render
python scripts/lizicut.py materials material-plan.json --output-dir output/materials --download
python scripts/lizicut.py validate timeline.json --media
python scripts/lizicut.py retime-captions original.srt cuts.json --output captions.srt
python scripts/lizicut.py render timeline.json --output film.mp4
python scripts/lizicut.py inspect film.mp4 --decode
```

FFmpeg 合成器接受主画面、独立透明叠层、SRT 和声音轨，执行裁切、适配、图层时序、透明淡入淡出、字幕、混音及导出；它不会把自然语言自动编译成复杂动画。检索、转录、语义筛选及生成由智能体使用实际可用工具完成；materials 助手只取得已核验文件并记录来源。

口播任务先读 [音画时间与粗剪](references/timing-and-roughcut.md)。roughcut 入口可辅助计算映射、字幕与复核点，但不自行作出语义删减决定；PR 路径把同一组保留源区间实际剪入序列，保留原始可编辑音视频，并完成间隙硬审计和字幕源回读/可见性验收。

## 最少交接与完成判断

简单任务用短说明即可。多镜头制作以实际 PR 工程为主，附必要的确认版本、删减理由、源/成片映射和素材来源；不要另造平行项目状态。分镜记录解释目的、背景/元素/模板、关键词、进出/阅读时间和声音。从候选到落盘再到上轨逐项核对；仅有搜索词、链接或提示词尚未完成。只有使用本包合成器时才维护其 JSON 合同。

检查实际目标尺寸下的阅读、图表口径、素材身份、字幕/音频同步、切点、画面边界和声音，再检查实际导出文件。逐帧编排使用明确帧号，声音保持源时钟；字幕不可见或显式行数超限先修复，阅读预算告警逐项结合真实字体与声音处理，不猜分词或仅调高限额掩盖问题。文件可解码和时间线合法证明技术连通，不单独证明剪辑审美或解释有效。自检与独立人工审片分别说明。

PR 任务交付实际 `.prproj`、关联素材、字幕和用户要求的视频；PS/AI/AE 实际参与时保留对应源文件及可重建的交接素材。说明字体和缺失依赖。搜索词、提示词、计划、静帧、预览、正式视频分别报告完成状态。MCP 连通、结构回读、真实导出、视听自检和独立人工审片各有边界；工具不足时报告具体缺口。发布、付费、上传和权限变化只在用户已授权范围内执行。
