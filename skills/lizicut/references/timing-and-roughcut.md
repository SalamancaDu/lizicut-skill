# 音画时间与粗剪

## 时间依据

| 输入状态 | 可以做什么 | 需要保持的边界 |
|---|---|---|
| 只有文稿 | 语义分镜、素材需求、估算时长 | 标为 estimated，不生成伪精确字级时间戳 |
| 已有音频 + SRT/词时间 | 校对文本、规划切点、对齐画面 | 先抽查识别错误、专名、数字及偏移 |
| 已有音频，无字幕 | 用已具备且获授权的转录/对齐能力 | 缺工具时不能用匀分字数冒充识别结果 |
| 明确要求静音固定时长 | 按节拍与阅读时间设计 | fixed 是有效时钟，无需强加旁白 |
| 字幕/图文配乐，不需要解说 | 按阅读和音乐设计固定时间，保留 BGM/音效 | 使用 nonverbal 音频模式；不是没有声音，也不必强配 TTS |

录音前可以做表达草案；最终录音确定后锁定时钟。合成语音或克隆声音是可选执行能力，使用前沿用本次费用与声音使用授权。已有录音优先利用，未经要求不重配音。

## 粗剪的目标

压缩不承担信息的冗余，保住说话意图、自然韵律和上下文。粗剪服务后续精剪，保留可编辑工程、切口理由和尚不确定的候选；不能为了降低时长把一句话剪成新的立场。没有词级证据时，优先按完整句段处理。

执行时先恢复原片、稿件和录音关系，校对转录并形成源时间；按下面的内容规则标记保留、删除和待复核候选。选完内容再收紧停顿，校听切口并检查前后画面，最后同步字幕和工程。已有授权允许智能体连续判断和执行，不逐刀请求批准；无法确认原意或事实的部分先保留。

## 重录择优

先确认几段确实在重说同一个解释单元。重述后的数字、主体、条件或观点有变化时，不仅是“更流畅的一遍”，要先判断是否为事实更新、限定补充或不同论证。

选择按以下优先关系，避免编造综合分数：

- 先满足事实、原意、数字、否定和限定完整；错误版本不能因表演更好而胜出。
- 再看句子与论证是否完整，能否自然接上前后文。完整可用的一遍优先于跨多遍拼词。
- 再比较可懂度、语气、语速、音量与背景一致性，以及主播口型、姿态和动作的可接性；不默认最后一遍最好，也不默认最短最好。
- 两遍都不完整时，可在原片真实存在的完整短语边界组合，逐口核查语义和声画。不得拼出原片没有表达的新事实。找不到可靠组合就保留较完整语境并标记具体缺口。

删除版本要指明替代的保留源区间及选择理由，并确认该替代没有又被其他决定删掉。保留版本中的必要铺垫、代词指向和后文承接要一并检查。

## 语义重复、口癖与转写重复

| 现象 | 判断与处理 |
|---|---|
| ASR 重复串句、错挂尾巴 | 对照声音和词时间先修转写。声音只说一遍时，修字幕，不切原片；原项目的 ASR repair 不是原片重录择优器。 |
| 同义赘述 | 对象、条件、时期、口径、结论，以及论据、例子、解释角度和叙事作用都无新增，且删后仍能理解，才作为删减候选；选择较完整的一段并标出保留表达。 |
| 强调、对比、章末回扣、列举 | 即使词相同，也可能承担不同作用；不能按相似度删除。 |
| 磕巴或启动失败 | 在真实声音中确认后，按完整短语或小句恢复顺畅，保护后面的有效起音；不追求逐字镊取。 |
| “嗯、那个、就是、然后”等 | 词表只提示候选。孤立、无信息且切口可接才删；“那个方案”“就是这个原因”有指向或强调，承担步骤关系的“然后”也应保留。 |

判断重复时至少比较前后完整句段，而不是只看相邻两个词。保留因果、转折、数量、单位、范围和代词所依赖的上下文。删掉一段后若下一句的“因此/这/第二点”失去所指，恢复必要铺垫或重新选择完整段落。

## 自我纠正

区分录制失误、讲述中的澄清和有意对比，不能凭“不是、应该说、准确地说”自动删前半句。

- “不是收入下降，是利润下降”若在强调指标差别，保留完整对比。
- “增长二十……说错了，是十二”要先核对实际录音、文稿和可用事实。录制失误已明确，且有完整正确表述时，才去掉错误分支与无用的纠错词。
- “营收增长，不过利润下降”新增了限定和反差，不是可丢弃改口；“准确地说”后新增的范围、分母或条件也不能顺手删掉。
- 正确口径未确定、改变主张，或删后只剩无主语的数字碎片时，先保留纠正过程并指出具体待核实内容。剪辑不能替用户认定哪项事实为真。

删除的错误分支与保留的正确表达都挂到源时间，重听完整新句，确认否定词、数字和限定没有反转。修字幕以实际保留音频为准，不用文字改写掩盖音频仍在说错。

## 呼吸、停顿与接缝

把停顿区分为语义/章节边界、强调/思考、正常换气和无信息闲置。波形低电平、VAD 或 breath_after 只能帮助定位，不能独立证明可删；低声词、擦音、弱读和尾音可能很轻。

正常换气优先保留。过响的独立吸气可在已有音频工具中局部降增益；不必删去整段呼吸。确需压缩时只收紧已确认的多余部分，保留起吸、呼气与下一句起音的自然关系；不把半个呼吸拼成断气，不在发声中间切。原项目的 120/160ms 等值是候选特征，不能当成所有人的呼吸目标。

先听切口附近一段完整表达；可从前后各约1—2秒开始，需要时扩到整个气口/句段。检查吞字、尾音截断、双重吸气、爆音、音色和环境底噪突变。必要时放宽边界、恢复一段停顿，或用同场真实底噪补接；没有底噪样本时不生成声音冒充原录音。

助手可在内部拼接点加很短的淡入/淡出来缓和点击声，默认5ms、可设0—20ms；它不改变区间长度，不把两段语音交叠，也不能修复切掉的字。需要更长交叉淡化、降噪或独立气口包络时在现有音频工具完成，并重新核对时间。

原代码低/中/高共享停顿语义，强度改变安全停顿删减预算及保护余量，而不是把全部语义边界阈值一律缩短。可从保守强度开始听切口，只有具体冗余仍在才加强，不追求固定删减比例。

来源代码的初始保护量（毫秒）可用于受控试剪，不能视作跨声音的保证：

| 强度 | 保留句头 | 保留句尾 | 最短片段参考 |
|---|---:|---:|---:|
| 低 | 64 | 176 | 1200 |
| 中 | 40 | 144 | 900 |
| 高 | 28 | 96 | 620 |

这些值依赖原系统的词时间与停顿策略。本包没有复刻原 ASR/置信度算法。缺置信度时不要假定为高；低置信度、时间戳冲突或语音不清时扩大保护并回听。

## 跳切与画面衔接

先检查切口两侧的头部位置、视线、口型、手势、道具和光线，不把声音顺畅等同于画面顺畅。优先在完整动作或自然静止处接；眨眼和转头只是观察线索，不能一律在其上切。视频与同期原声先保持同一源区间。

依次选择适合本段的处理：

1. 微调源切点或改用另一遍完整表述，保持语义、气口和动作可接；不为修画面截掉有效声音。
2. 允许克制、可接受的硬切；粗剪可以保留清楚标记的跳切供后续精剪。
3. 需要覆盖时，在切口前建立与内容相关的真实资料、图表或补充镜头，覆盖到新姿态稳定再返回。覆盖画面不改变下方已剪人声，字幕仍使用同一时间；素材本身的原声不要自动混入。
4. 只有原素材分辨率与构图允许且符合现有风格时，才少量改变景别；不能每刀推近，也不依赖光流、假运镜或人脸变形掩盖问题。需要声画错开的 J/L cut 时保护出镜口型，落到明确的轨道和区间上。

没有合适覆盖素材时先留硬切及复核点，或恢复该刀；不能把“建议加 B-roll”写成“已经覆盖”。本包 roughcut 只做同步硬切与短音频淡化，visual_note 是待执行说明。要覆盖时，在生成的 timeline.json 添加真实 overlays 并实际渲染，或在已有剪辑工程中实施。

用户已有 Premiere 等工程时，优先在可恢复的序列副本上操作；发现当前可用的连接和工具后，用同一组源区间实施、创建切口/待复核标记，并检查实际序列。不要把本包 JSON 声称成已经创建的 PR 工程，也不要为撰写 Skill 操作用户当前项目。粗剪后由用户精剪的任务交付可编辑序列、关联素材和删减理由。

## 源时间与成片时间

源时间标记原素材位置；成片时间标记剪后位置。剪掉一段后，字幕、旁白、原声、主播视频与关联画面都要使用同一映射。单改字幕起点会形成越往后越不同步的问题。

源时间零点按容器的共同起点计算，不能把音视频各自第一帧都当零点。助手读取所选流的起始位置与结束位置，保留原有音频延迟；延迟前的区间填静音，不把声音提前。非零容器时间戳先换算为同一相对时钟。缺少必要时间信息、视频在零点尚无画面或时间关系异常时，先准备可核查的同步主素材，不猜偏移。roughcut-map.json 的 source_timing 记录各流在源时钟下的起止。

保留区间按源时间升序且不重叠，每个区间映射为成片上连续的区间。对视频帧边界做必要取整时，要同步使用取整后的声音与字幕范围，并保留误差依据。不要依赖最后一镜伸长掩盖前面累积错误。

辅助工具接受：

```json
{
  "source_duration_ms": 8000,
  "kept_ranges": [
    {"start_ms": 0, "end_ms": 3000},
    {"start_ms": 5000, "end_ms": 8000}
  ]
}
```

`retime-captions` 只重映射字幕，不替你剪音频或判断删词。完全落在删掉范围的字幕会去掉；完全位于保留区间的字幕会移动；字幕跨越删减边界时会报出具体条目，要求先根据音频拆成准确子句。它不会把跨切口的整句复制到两边。

## 字幕与视觉层

- 字幕保留准确口播；按自然语义换行，避免把数字与单位、姓名或短语拆开。同时核对实际行宽、行数、阅读速度和停留时间；预算按画幅、字体、语言和字幕用途调整，不能只检查时间先后合法。
- 主板保留关系、关键数字、节点和短结论，不与字幕整段重复。
- 重点文字和图形在相关词附近出现；起点不必与背景完全一致。先确定关键词或语句的实际声音范围，再选“听到时开始揭示”或“听到时已经可读”；需要后者时将入场提前一个动作时长。不能在动画尚未完成时就切走，也不能为追求逐字同步挤掉读图时间。
- 同单元的背景通常先建立，元素与模板可分批进入，在内容交接处一起收束；有明确承接关系的锚点可跨镜延续。背景换镜、前景入场、板面更新、字幕换行是不同事件，不必共用一个切点。
- 只有句级时间时，将该句的主要关系提前准备好或在整句范围内保守揭示；精确卡到某个词需要核听或真实词时间，不能按字数匀分。每层保留入场、稳定阅读和退出所需的实际时间。
- 数字、单位、正负、百分比、时期和主体身份需要逐项核对。
- 先在实际尺寸看字幕与重点是否互相遮挡，再抽听开头、中段和结尾的同步；粗剪切口应逐个听。

本包合成器的 SRT 必须已在成片时钟下。按[字幕合同](execution.md#字幕)运行 validate --media，处理不可见/行数错误及逐条阅读告警，再检查真实字体画面。超载时依据声音拆准确子句、延长可读保持或重排版面，不凭字数分配新词时间；无法核听就保留时间证据缺口。程序不能验证识别文字是否真的与声音一致。

## 从决定到实际执行

先依据实际素材与上述规则作出决定，再使用[粗剪执行入口](execution.md#口播粗剪入口)生成并执行计划。每条决定记录源区间、类别、理由与证据；未列出的内容默认保留，待复核候选保留并映射到成片位置，保护区间不能被其他删除覆盖。

这些决定由当前智能体在已授权范围内完成；timing_checked 是已检查时间的声明，不是新的用户批准门槛或机器证明。无法核听、没有可信时间或工具不足时，保留不确定段并说明具体缺口，不虚构核听结果。实际导出后检查每个新接缝，更新对应源层；没有做独立审片就保留作者自检边界。
