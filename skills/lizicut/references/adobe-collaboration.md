# PS / Illustrator / AE 可选协作

只在镜头确实需要定版设计、可编辑矢量或复杂动效时使用。PR 仍是整片编排、对齐和输出的主工程。这些软件不构成每条视频的固定前置步骤，用户指定的软件和实际可用能力优先。

## 选择与发现

| 工作 | 合适的执行端 | 交接给 PR 的内容 |
|---|---|---|
| 图片处理、抠图、照片合成、栅格定版 | Photoshop | 分层 PSD，以及实际所需的透明 PNG/TIFF 或逐层素材 |
| 标题字形、矢量图标、精确图解和可缩放形状 | Illustrator | 可编辑 AI，以及按图层/元素导出的 PNG 等实际可导入素材 |
| 逐元素图表、形变、复杂遮罩、表达式、合成动效 | After Effects | AEP、关联源、明确规格的中间渲染或已验证的 MOGRT |
| 简单位置、缩放、透明度、效果与镜头交接 | Premiere | 在实际序列内完成，不为简单动作强制另开 AE |

先发现现有 MCP、宿主脚本接口或用户已有工作流。只有发现并验证可控能力才执行；MCP 工具存在不等于软件已连接。没有专用 MCP 时，可在本次授权内使用已安装软件提供的脚本接口，先确认版本、真实可执行文件和当前工程状态；不把任意 shell 执行称为 Adobe MCP。新安装、插件、权限或付费服务按原授权边界处理。

保留用户当前未保存工作；新建独立文档/工程，或在用户指定副本上编辑。脚本只写本次文件，临时改变的标尺、颜色、对话框等应用偏好应恢复；不关闭无关文档。缺少软件时说明该分支不可执行，可以继续 PR 原生能力覆盖的部分；用户明确指定的软件交付不能被另一种工具悄悄替代。

## 从动效思路到可交接定版

先给出实际画面载体、信息关系、元素层级、字幕区和稳定阅读状态。标明哪些元素独立运动，哪些保持不动。PS/AI 定版采用最终画幅及真实文字/数字，动画需要变化的数字、箭头、节点与主体不能合并进不可编辑背景。

每项资产在已有分镜/素材记录中保留必要信息即可：

- 对应解释单元/PR 使用区间、用途与已确认内容版本。
- 源文件和导出文件的真实路径，图层/元素身份及需要独立控制的部分。
- 画幅、像素比例、帧率、有效时长/首帧、颜色、alpha，以及是否有需要的声音。
- 修改归属：改字/数据回到定版源，改复杂运动回到 AE，改整片时间或声音回到 PR。

审阅最终尺寸下的中文、数字、单位、尺度、层级和透明边缘。静帧确认的是定版；不能据此声称动作或声音通过。已有定版授权可以继续执行，用户保留的审阅节点按原约定等待，不额外发明审批轮次。

## Photoshop / Illustrator 实施与交接

在真实文档中制作并保存分层源。需要逐元素运动时导出独立元素，保留一致画布/坐标或明确锚点；检查透明画布没有被裁到不一致的边界。只有单张定版时可导出整图，说明哪些内容已烘焙。

PR 可用实际支持的分层导入方式时先验证；无法稳定指定导入选项时，交接已检查的独立 PNG 等素材，在 PR 分轨编排，同时保留 PSD/AI。不能因为导入成功就声称分层、矢量可编辑或字体已嵌入；AI 源交付与 PR 中实际使用的栅格资产分别说明。

替换时沿用元素身份和对齐基准。改动了画布、边界、字体或字号后重新检查 PR 中的位置、缩放、字幕遮挡和关键帧；不要只替换文件后假定原动效仍正确。

## After Effects 实施与交接

新建/沿用本次 AEP，导入真实定版与素材，按最终规格建合成；帧率、像素比例、工作区间、起始帧和颜色与 PR 协调。按语句与阅读预算实施入场、揭示、保持和交接，保留图层、关键帧/表达式及可修改文字。

优先选择当前环境已经验证的交接方式：

- 无需透明：渲染合适的中间视频，明确是否含音频。
- 需要透明：渲染带真实 alpha 的中间格式或 RGBA 图片序列，检查实际通道、帧数、直通/预乘边缘。普通 H.264 MP4 不作为透明交接。
- 需要 PR 可修改模板：使用真实可导出、可导入且字段已经验证的 MOGRT；不要把任意 AEP 当模板。

发现并核对本机实际渲染模板/编码器，不硬写不存在的名称；队列提交后等实际完成并检查文件。保留 AEP 和依赖，不能只交一段不可修改的中间视频。

推荐的 PremiereMCP 当前不提供可依赖的 `import_ae_comps` 路径，其文档记录直接 `.aep` 导入曾失败并可能卡住桥接。因此不默认承诺 Dynamic Link，也不拿真实用户工程反复试导 AEP。另有已验证的连接方式且本次允许时才使用；通常先渲染，再导入 PR。[项目限制](https://github.com/DutchErwin/PremiereMCP#current-status)

## 回到 PR 验证

导入实际交接素材，核对源长度、帧率、尺寸、alpha、颜色和多余音轨。根据素材的动画首帧/可读保持安排序列起点，不能把素材局部时间直接当序列时间。与实际旁白、字幕和背景逐项对齐，检查首末帧、接缝和重采样/循环。

修改后从所属源重新导出，刷新或替换正确项目项，再检查受影响片段；有多个实例时明确本次替换范围。最终整片仍从 PR 输出，连同源设计、AE 工程和中间素材交付。没有实际操作的软件只标“可选流程已定义、未实测”，不能因为另一软件导出成功而一并宣称通过。
