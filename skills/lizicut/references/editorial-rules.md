# 剪辑判断与画面选择

## 从整篇到解释单元

先找观众的问题与最终应理解的结论，检查论据能否支撑结论。保留用户观点，不为制造开头悬念夸大事实。文稿可改写范围不清时，先保留原文进行画面规划。

一个解释单元围绕一个需要看懂的关系，可以跨几句话，也可以只占一句的一部分。单元之间应有可说明的推进：提出问题、展示证据、解释机制、比较方案、收束结论。开头/解释/比较/数据/引用/行动/结尾是可用的叙事角色，不要求每条视频集齐全部角色。

分清三件事：

| 判断 | 问题 | 例子 |
|---|---|---|
| 画面载体 | 观众主要看到谁、什么空间？ | 主播、现场视频、历史图片、设计画面 |
| 信息关系 | 画面要使什么关系可见？ | 时间、比较、机制、空间、并列、量级 |
| 证据身份 | 画面能够证明什么？ | 原始报告、原声、数据、示意、气氛素材 |

三者可以组合。主播可带图表；实拍可带标签；证据截图可进入时间线。不要因选了主播就清空模板，也不要因出现数字就自动变成图表。

判断顺序是“这一段为什么值得看 → 观众要理解什么 → 什么载体最有效 → 需要哪些层”，不能先按财经/科技等行业名称或现有模板库存反推整段画面。信任与观点承接偏向主持；数据和抽象关系偏向可控图解；叙事、动作与环境偏向资料画面。多种需求同在时先确定主任务，其余作为辅助。

## 11 类候选表达

沿用原项目的词汇，便于检索；它们是工具箱，存在交叉。先选主解释任务，再决定辅助方式。

| 候选 | 成立条件 | 容易误用的情况 |
|---|---|---|
| 地图 Map | 位置、距离、路径或地缘关系本身影响理解 | 文案只提到一个地名，空间并不重要 |
| 时间线 Timeline | 多个时点之间的演变或顺序是重点 | 只有一个年份，用作标题即可 |
| 图表 Chart | 有足够且可比的数据表达趋势、比较或构成 | 只有“增长”两字，没有数据；不得编曲线 |
| 图解 Diagram | 因果、机制、层级、流向需要可见 | 只是几个并列名词，不必强画因果箭头 |
| 物料展示 Showcase | 报告、书籍、新闻、界面等原始载体需要被看见 | 截图不可读、没有突出证据或与论点无关 |
| 原声/波形 Audio | 声音本身是证据或体验对象，且有可用音源 | 旁白说“他说”但没有原声；不能伪造原声 |
| 卡片 Card | 几个并列项目或可操作步骤需要组织 | 项目其实相互作用，应画机制而不是平铺 |
| 数字 Number | 单个数值或量级值得记住，口径明确 | 每一个数字都放大，失去重点 |
| 文字 Text | 定义、问题或结论值得短暂停留 | 把整段口播搬上屏幕 |
| 拼贴 Collage | 集合、生态或多声部需要整体感 | 用无序堆图代替比较或证据链 |
| 通用图文 Media-text | 具体对象与少量说明已足够 | 为方便套用而吞掉本应使用的关系表达 |

主播用于承接解释、建立信任、观点或章节交接；仅有“我认为”不强制出镜。缺主播素材时可改用准确的设计画面，但需保留该段的解释责任，不伪造人物。

## 连续性

同一解释任务优先保留对象、坐标、尺度、字体和标签，把新增关系逐步揭示。可采用“进入—持有—推进—收束”的状态思路，不必每句重置。换章节时给新的锚点、标题或证据，帮助观众重新定位。

对证据板，延续时同时保留来源身份和必要时间/口径。不能沿用一张无关生成背景，造成新论点仍由上一份证据支持的错觉。

明确下一镜是沿用、更新还是重建：沿用时保留来源及对象；更新时标明哪项数据/时期改变；重建时用新标题、来源或主体重新定位。跨板桥接要有共同锚点，不在“所以”“但是”处机械换镜。没有承接价值的独立单元可以直接开始，不强造过渡。

## 决策例子与反例

**演示文案：**“营收在涨，利润却在下降。”

- 任务：使反差可见；没有数据时做定性对照板，不制作伪精确坐标图。
- 时序：同板先出现营收方向，再出现利润方向，最后停留让观众比较。
- 文字：关键词与方向进入主板，完整句子进入字幕。
- 切镜：两个分句不用拆成两镜；若下一句解释成本上升，可沿用关系并补入成本节点。

**演示文案：**“他说，这家公司改变了一切。”

先确认谁说、出处和原声是否存在。有原始录音且需要听声音时用原声/波形；只有文字来源时用准确引用；无来源时保留待核实，不按“他说”直接调用波形。

**演示文案：**“第一步收集数据，第二步处理，第三步反馈。”

说明操作顺序时用步骤；解释反馈如何改变下一轮收集时用闭环图。选择取决于要解释的关系，不取决于“第一步”关键词。

## 节奏原则

原项目的画面镜头 2—5 秒、模板背景 5—10 秒、连续纯画面不超过 15 秒可用作初始观察值。超过一分钟后纯画面总量固定为 10—30 秒的规则不作为全片约束。根据语速、信息量、资料的阅读成本与影片长度判断。

需要呼吸时可减少信息、延续画面或保留停顿；不能为了凑纯画面比例撤掉关键证据。长解释板可以持续，只要状态有推进且有足够阅读时间。快速开头不意味着主体也持续高频刺激。

排完整片再检查连续区间：全是静态字卡是否丢失对象、过程与空间？连续资料蒙太奇是否让关键逻辑只靠听？没有信息推进的长背景是否只是填时间？根据缺失的解释功能补动作、证据或简化板面；需要观看动作本身的段落可以长留，不能把取消固定配额理解成不检查全片节奏。
