# v0.2.2 视频素材搜索路由复核

本版本把思维导图中的视频搜索方法写入 Skill：

- 真实人物和热点事件先用准确主体加媒体类型词与信息功能关键词检索；
- 优先尝试 `纪录片/documentary`、`历史/history`、`故事/story`、`采访/interview`、`档案/archive`、`官方/official`、`现场/footage` 等高信息密度词；
- 中文和英文查询分开保留，逐轮只调整一个检索维度；
- 官方机构、原始发布者、新闻机构原页、档案库和完整采访优先；
- 高质量同时考虑来源、上下文、实际画面/声音可用性和授权，不用排名或分辨率替代核验；
- 结果页、缩略图和预览地址不能当作已取得素材。

验证通过：`check_project.py`、`quick_validate.py`、27 项时间线/字幕测试、6 项粗剪测试、6 项素材测试。源 Skill、安装版和备份版同步为 17 个文件。

本版本更新的是搜索规则和记录要求，没有执行新的用户项目素材搜索，也没有修改用户的 Premiere 工程。
