# v0.2.1 粗剪与字幕规则复核

本版本根据 AEPS 电脑自动剪辑评估更新，不修改用户工程，也没有把静态规则更新冒充新的 PR 实剪结果。

更新范围：

- V1/A1 默认 0 帧间隙；完整句子/段落结束才允许 5–8 帧；超过 8 帧失败。
- 区分时间线空洞与源片段内部静音、黑帧和无意义动作。
- 写入前后核对目标项目、目标序列和活动序列；处理 `results.filter is not a function` 等回包错误时先回读实际状态。
- 使用 `sourceSrtPath` / `sourceSrtOffset` 时回读原始字幕文本、换行和源/序列时间；不支持时直接解析同一份 SRT。
- 原生字幕轨、MOGRT/烧录路径和最终视频字幕可见性分层验收。
- 无标点字幕作为显式样式配置，不修改原始 SRT 事实文本。

验证：

- `scripts/check_project.py` 通过。
- `skill-creator` `quick_validate.py` 通过。
- 27 项时间线/字幕测试、6 项粗剪测试、6 项素材测试通过。
- 安装版与备份版已同步 17 个 Skill 文件。

本版本未重新操作用户的 Premiere 工程；真实 PR 验收仍需在目标机器上使用已重启的新 Premiere MCP，并按新间隙审计和字幕可见性门槛执行。
